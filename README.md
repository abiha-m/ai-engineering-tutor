# 🔧 AI Engineering Tutor

An AI-powered tutoring application that helps engineering students understand complex technical concepts through structured, easy-to-follow explanations.

The application uses an AI model to transform an engineering concept into a learning-focused response containing a definition, key formula, step-by-step reasoning, real-world example, analogy, common mistakes, and difficulty level.

Built with **Python, Streamlit, and the OpenAI API**.

---

## 🚀 Overview

Engineering concepts are often difficult to understand when explanations are either too theoretical or too brief.

AI Engineering Tutor was built to explore how generative AI can provide more structured educational explanations.

Instead of returning a single block of text, the tutor organizes each response into multiple learning components:

- 📌 Definition
- 📐 Key Formula
- 📋 Step-by-Step Application
- 🌍 Real-World Example
- 🔍 Analogy
- ⚠️ Common Mistakes
- 📘 Difficulty Level

The goal is to make technical concepts easier to understand while maintaining a consistent response structure.

## ✨ Current Features

### 📚 AI Concept Explanations

Users can enter an engineering concept and receive a structured explanation generated by AI.

Example concepts include:

- Ohm's Law
- Thevenin's Theorem
- Newton's Second Law
- First Law of Thermodynamics
- Fourier Transform

### 🧠 Structured AI Responses

The application prompts the model to return structured data containing:

```json
{
  "concept": "Concept name",
  "definition": "Clear explanation",
  "key_formula": "Relevant formula",
  "step_by_step": "How the concept is applied",
  "real_world_example": "Practical example",
  "common_mistakes": [
    "Common mistake 1",
    "Common mistake 2"
  ],
  "analogy": "Simple analogy",
  "difficulty_level": "Basic / Intermediate / Advanced"
}
```

This structure allows the application to display AI-generated information in clearly separated learning sections.

### 💰 API Cost Tracking

The project includes a custom cost-tracking component that monitors AI API usage by operation.

The Streamlit sidebar displays session API usage and provides a breakdown of recorded operations.

### 📖 Session History

Recently generated explanations are stored using Streamlit session state so users can quickly review concepts they explored during the current session.

### 📥 Downloadable Explanations

Generated explanations can be exported as text files for later review.

### 🛡️ Error Handling

The application includes handling for:

- API errors
- Empty responses
- Invalid JSON responses
- Missing configuration
- Unexpected model output

## 🏗️ Architecture

The application uses a modular architecture that separates the user interface, AI orchestration, prompt construction, and usage tracking.

```text
User
  │
  ▼
Streamlit Interface
  │
  ▼
Tutor Engine
  │
  ▼
Concept Explainer
  │
  ▼
OpenAI API
  │
  ▼
Structured Response
  │
  ▼
Streamlit Explanation View

Tutor Engine
  │
  └────────────► Cost Tracker
```

### Main Components

**`app.py`**

Provides the Streamlit user interface, navigation, session history, explanation display, and download functionality.

**`tutor_engine.py`**

Handles AI API communication, engineering context, response generation, and integration with the cost tracker.

**`concept_explainer.py`**

Constructs structured educational prompts and processes AI responses into a consistent explanation format.

**`cost_tracker.py`**

Tracks token/API usage and provides cost statistics by operation.

## 🧠 Prompt Engineering

A major focus of this project is generating responses that are useful for learning rather than simply asking an AI model to "explain" a topic.

The prompt defines an engineering-tutor role and requests specific educational components.

The response is expected to contain:

1. A clear definition
2. A key formula
3. Step-by-step application
4. A real-world example
5. Common mistakes
6. An intuitive analogy
7. A difficulty classification

Using a structured output format makes the responses easier to validate, parse, and present consistently in the user interface.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/abiha-m/ai-engineering-tutor.git
cd ai-engineering-tutor
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the API key

Create a `.env` file in the project directory:

```text
OPENAI_API_KEY=your_api_key_here
```

Do not commit the `.env` file to GitHub.

### 5. Run the application

```bash
streamlit run app.py
```

Streamlit will open the application in your browser.

## 🔐 Security

API credentials are stored using environment variables rather than directly in the source code.

The repository's `.gitignore` excludes:

```text
.env
venv/
__pycache__/
```

This helps prevent API credentials and local development files from being committed to the repository.
